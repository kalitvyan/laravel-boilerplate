# Тесты

- Pest. Feature и Integration используют `RefreshDatabase` глобально через
  `tests/Pest.php` — не подключай трейты работы с БД в файлах.
- Замыкания на верхнем уровне файла не видят `$this` и `test()`. Всё, что требует
  контейнера, — параметром или в `beforeEach`.
- Feature-тесты валидируют запрос и ответ против спеки. Отключай через
  `withoutContractValidation()` только для намеренно невалидных запросов.
- Утверждения о транзакциях — относительные (`$before + 1`): тест уже внутри
  транзакции `RefreshDatabase`.
- `jsonb` не сохраняет порядок ключей — сравнивай через
  `toEqualCanonicalizing()`.
- Фикстуры — в `tests/Fixtures/`, по пространству имён контекста.
