# Доменный слой

- Никаких `Illuminate\*` и `Carbon`. Время — `DateTimeImmutable`, текущее время
  передаётся параметром либо через `Psr\Clock\ClockInterface` из Application.
- Value object валидирует себя: приватный конструктор, именованные фабрики,
  доменное исключение при нарушении.
- У агрегата два вида конструкторов: `register()`/`create()` для новых фактов
  (вызывают `recordThat()`) и `restore()` для подъёма из хранилища (событий не
  записывает).
- Исключения наследуют `DomainError`. Их сообщения показываются клиенту —
  пиши их соответственно.
- Интерфейс репозитория возвращает `?Aggregate`, «не найдено» — решение сценария.
- Проверки, зависящие от состояния агрегата («отменить можно только до
  отгрузки»), — метод агрегата или доменная политика, а не право в конфиге.
