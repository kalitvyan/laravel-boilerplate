# HTTP API

- Spec-first: операция описывается в `docs/api/paths/<context>/` до кода.
  После правки спеки — `make client`.
- Ответ — JSON без обёртки. Коллекция — объект
  `{ "items": [...], "page": { "nextCursor", "limit" } }`, не массив.
- Ошибки — RFC 9457. Доменное исключение сопоставляется со статусом в
  `ProblemMap` контекста (в `register()` провайдера), поиск идёт по иерархии
  классов. Код ошибки — `context.snake_case`, он часть контракта.
- Контроллер собирает команду, берёт актора через `CurrentPrincipal::of()`,
  генерирует UUIDv7 до отправки. Бизнес-логики в контроллере нет.
- FormRequest проверяет форму ввода, бизнес-правила остаются в домене.
- Middleware, которое трогает БД или модели, — это Infrastructure, не
  Presentation.
- Каждый вызов в feature-тестах проверяется против спеки автоматически.
