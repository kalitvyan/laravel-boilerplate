# Frontend

- Браузер обращается только к своему origin. К API — через `/bff/*`.
  `NEXT_PUBLIC_*` для адреса API не используется.
- Сессия — зашифрованный httpOnly cookie. Токены в браузер не попадают.
- Переменные окружения читаются лениво (`lib/env.ts`): обращение на верхнем
  уровне модуля ломает сборку.
- Клиент API создаётся через `api()`, а не на импорте.
- Данные для интерфейса — TanStack Query через `bff()`. Мутации — Route
  Handlers, не Server Actions.
- Ошибки от BFF — Problem Details, как у API. Ошибки валидации
  раскладываются по полям формы через `pointer`.
- Клиентская валидация входа не повторяет политику паролей: это подсказка
  атакующему. Строгие правила — только при регистрации.
- `packages/api-client/src/schema.d.ts` генерируется — правка только через
  `make client`.
