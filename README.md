# Laravel Boilerplate

API-first boilerplate: Laravel 13, PHP 8.5, DDD / Clean Architecture,
event-driven (transactional outbox), FrankenPHP + Octane, PostgreSQL, Redis,
S3-compatible storage, Next.js BFF. Kubernetes-ready.

## Quick start

```bash
make help
```
