# 0009. RustFS вместо MinIO для локального S3

- Статус: Принято
- Дата: 2026-09-18

## Контекст

Для локальной разработки нужно S3-совместимое хранилище. Стандартным
выбором был MinIO, но в конце 2025 года его community-версия перестала
публиковать Docker-образы, перешла в режим поддержки и была заархивирована;
в 2026 году namespace был удалён с Docker Hub.

## Решение

Локально используется RustFS. В коде работа с файлами идёт через порт
`FileStorage` с реализацией на Flysystem S3, поэтому провайдер меняется
конфигурацией.

## Альтернативы

Garage, SeaweedFS, community-форк MinIO. Любой подошёл бы: выбор локального
эмулятора не влияет на код.

## Последствия

- Для presigned URL используется отдельный диск с публичным endpoint:
  подпись SigV4 включает заголовок Host, поэтому подменить хост в готовой
  ссылке нельзя.
- Поддержка переопределения заголовков ответа у S3-совместимых хранилищ
  может отличаться от AWS; при подключении нового провайдера это проверяется
  отдельно.
- Порт `FileStorage` изолирует приложение от особенностей провайдера.
